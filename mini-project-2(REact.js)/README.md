# React Lottery Game

A simple interactive lottery game built with **React.js**.

Generate a ticket, check the winning condition, and celebrate when you hit the jackpot.

## Features

* Random ticket generation
* Dynamic winning condition
* Jackpot animation
* Responsive UI

## Tech Stack

**React.js • JavaScript • CSS • Vite**
